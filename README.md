# VidyaMandala


## Getting started

1. Clone the repo - `git clone https://github.com/00Pratik-Biswas00/VidyaMandala.git`
2. Add your envs.
3. Client (`cd client`) & Server (`cd server`) side respectively - `npm i` and then `npm run dev`
4. ML server (`cd ml-services`) - `pip install -r requirements.txt` and then `python -m uvicorn app:app --host 0.0.0.0 --port 5000 --reloadkathon\vidyamandala`

## Description

PACE introduces the following key enhancements:

1. Course-wise AI Mock Interviews for practical readiness.
2. AI-Powered Quiz Tool to reinforce understanding through practice from article links.
3. PDF Summaries and PDF-to-Quiz Conversion for efficient revision.
4. Automatic Block Diagram Generation to support visual learning.
5. Daily Learning Plan Generator tailored to user-defined deadlines.
6. Enrollment-Based Course Access with intelligent course recommendations based on individual learning needs.

By integrating these features, PACE significantly enhances the learning experience, making the platform more interactive, personalized, and effective for users.
